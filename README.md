# BRISC PyTorch coursework (Tasks 1–3 + Bonus)

Bachelor Informatics coursework at Goethe University: brain MRI (BRISC) with PyTorch.

| Folder | Exercise | Topic |
|--------|----------|--------|
| `task1/` | Exercise 1 | U-Net tumour segmentation |
| `task2/` | Exercise 2 | Convolutional autoencoder |
| `task3/` | Exercise 3 + Bonus 4 | ConvVAE, latent interpolation, prior samples, frozen ResNet-18 features |

Task 3 includes metrics, interpolation / prior / ResNet figures under `task3/results/`.

Large model checkpoints (`*.pt`) and the raw BRISC dataset are not in this repository.
