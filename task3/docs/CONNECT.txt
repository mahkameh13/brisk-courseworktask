GPU Jupyter for my_task3.ipynb (cluster notes)

Use the login host you already SSH to (not a broken DNS name).

Tunnel template:
  ssh -N -L LOCALPORT:GPUNODE:PORT USER@LOGIN_HOST

Then open http://127.0.0.1:LOCALPORT/lab with the token printed in the job log.
Open the notebook under your work directory and check:
  import torch
  print(torch.cuda.is_available(), torch.cuda.get_device_name(0))
